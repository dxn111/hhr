# Contributing

Thanks for helping make HHR easier to discover and use. This repository is for installation, usage, and project information; the HHR application is maintained separately.

## Documentation changes

1. Open an issue for a larger change, or send a pull request for a focused correction.
2. Keep install commands aligned with the hosted installer and the published npm package.
3. Check links and code blocks before submitting. Use synthetic examples in screenshots.
4. Do not include API keys, session files, private code, or unredacted logs.

## Pull requests

Keep each pull request focused and describe the user problem it solves. Include before-and-after screenshots when changing a visual asset or README layout.
